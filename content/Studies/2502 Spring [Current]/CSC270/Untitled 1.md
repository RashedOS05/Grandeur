# Cache

## Example: 4 blocks, 4 bytes 8-bit addresses

### Offset: 2 (2^2 = 4)

The offset is the power over 2 needed to represent the block size

### Index

How many digits are needed to represent the value of the blocks (0's and 1's per digit count as 2 values)

### Tags

\= Tags = n-bit addresses - index -  offset
